# rosalind_solutions
Homework 4 : Solutions to Rosalind bioinformatics problems 
DNA : counted nucleotides (dna: str), Returns counts of 'A,C,G,T'
RNA : Transcribed DNA to RNA, dna: str, replace 'T' with 'U'
REVC : reversed complement
GC : searched for highest_gc_record(fasta_text:str), we took FASTA-formatted text, return 'ID, gc_content. 
HAMM : counted the number of differing positions between equal length
PROT : Translates_rna (rna: str), translates RNA string into protein string
SUBS : 'find_motif(s:str, t:str), returns all starting positions (1-based) where substring 't' appears in 's'.
PRTM : calculated protein mass
